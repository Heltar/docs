# Welcome

Documentation for the WhatsApp Business API platform.

## What is this?

A complete solution for businesses to communicate via WhatsApp:

| Feature            | Description                                          |
| ------------------ | ---------------------------------------------------- |
| **Inbox**          | Manage all WhatsApp conversations in one place       |
| **Contacts**       | Store and organize your customer database            |
| **Bulk Messaging** | Send campaigns to multiple contacts at once          |
| **Templates**      | Create and manage approved message templates         |
| **AI Agent**       | Build AI chatbots that handle conversations          |
| **Code Editor**    | Create custom functions for your chatbots            |
| **Calls**          | Handle WhatsApp voice calls                          |
| **Integrations**   | Connect with Shopify, CleverTap, WebEngage, and more |
| **Analytics**      | Track delivery, engagement, and performance          |
| **API**            | Integrate with your own systems                      |

## Main Features

### Inbox

Your central hub for all WhatsApp conversations. Three-panel layout with chat list, messages, and contact details.

### Contacts

Manage your customer database. Import via CSV, add custom attributes, and organize with tags.

### Bulk Messaging

Send template messages to multiple contacts. Upload CSV, select template, map variables, and send or schedule.

### AI Agent

Create AI chatbots with custom system prompts and functions. Test in playground before publishing.

### Code Editor

Write Python handlers for chatbot functions. Create JSON configurations for chatbots and tool definitions.

### Calls

Handle WhatsApp voice calls with floating panels, ringtone controls, and Voice Bot integration.

# Settings

Configure your workspace, team, and preferences. Settings uses a sidebar navigation with collapsible categories.

**Navigation**: Click **Settings** in the left sidebar

---

## Interface Layout

### Sidebar Navigation

- **Search bar** - Filter settings by name
- **Theme toggle** - Light/Dark/System in header
- **7 collapsible categories** with settings items
- **Logout** option at bottom

### Settings Categories

| Category                    | Settings Count | Description                           |
| --------------------------- | -------------- | ------------------------------------- |
| **Account & Team**          | 6 items        | Business accounts and team management |
| **Profile & Setup**         | 4 items        | WhatsApp profile and configuration    |
| **Communication**           | 7 items        | Messaging and automation settings     |
| **Development & Analytics** | 5 items        | API and analytics                     |
| **Billing & Payments**      | 3 items        | Wallet and payments                   |
| **Appearance**              | 4 items        | Theme and display                     |
| **Bot**                     | 3 items        | Chatbot settings (if enabled)         |

## Quick Access

### Finding Settings

- Use the **search bar** in the sidebar to quickly find any setting
- Categories automatically expand when search matches

### Keyboard Shortcut

Press **Ctrl + K** anywhere in the app to open global search.

---

## Tips

> [!TIP]
> Collapsed categories save space. Click the arrow to expand/collapse.

> [!TIP]
> Settings changes are saved automatically when you click Save or toggle a switch.

> [!TIP]
> Some settings require specific permissions. Contact your admin if a setting is unavailable.

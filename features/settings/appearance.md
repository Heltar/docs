# Appearance & Preferences

Customize how the platform looks and behaves for you.

**Navigation**: Settings -> Theme / Tables / Notifications

## Theme Settings

Choose your visual theme.

### Available Themes

| Theme      | Description                  |
| ---------- | ---------------------------- |
| **Light**  | Bright background, dark text |
| **Dark**   | Dark background, light text  |
| **System** | Match device settings        |

### Setting Theme

1. Go to **Settings** -> **Theme**
2. Select your preferred theme
3. Changes apply immediately

### Benefits of Dark Mode

- Reduced eye strain
- Better for low-light environments
- Lower battery usage on OLED screens

## Table Customization

Configure how data tables display.

**Navigation**: Settings -> Tables

### Column Visibility

Choose which columns to show:

1. Open any table view
2. Click **Columns** button
3. Toggle columns on/off
4. Drag to reorder
5. Save preferences

### Available Columns by Table

**Contacts Table:**

- Phone Number
- Name
- Email
- Tags
- Created Date
- Last Message
- Assigned Agent
- Custom Attributes

**Campaigns Table:**

- Campaign Name
- Template
- Status
- Sent Count
- Delivered
- Read
- Created Date
- Scheduled Time

**Templates Table:**

- Template Name
- Category
- Status
- Language
- Created Date
- Last Used

### Column Width

Resize columns:

- Drag column borders
- Double-click to auto-fit
- Settings are saved

### Sorting Defaults

Set default sort order:

1. Click column header to sort
2. Click again for reverse
3. Hold Shift for multi-column sort

### Pagination

Set items per page:

- 10 (faster loading)
- 25 (default)
- 50
- 100 (more scrolling)

## Notification Preferences

Control toast notifications and alerts.

**Navigation**: Settings -> Notifications

### Notification Types

| Type        | Description                   |
| ----------- | ----------------------------- |
| **Success** | Action completed successfully |
| **Error**   | Something went wrong          |
| **Warning** | Attention needed              |
| **Info**    | General information           |

### Desktop Notifications

Enable browser notifications:

1. Click **Enable Desktop Notifications**
2. Allow in browser prompt
3. Notifications appear even when tab is hidden

### Sound Notifications

Configure sounds:

| Event             | Default  |
| ----------------- | -------- |
| New Message       | Enabled  |
| Assignment        | Enabled  |
| Campaign Complete | Enabled  |
| Error             | Disabled |

### Notification Duration

How long toasts display:

- 3 seconds (quick)
- 5 seconds (default)
- 10 seconds (longer read time)
- Manual dismiss only

### Do Not Disturb

Temporarily disable notifications:

1. Click **Do Not Disturb**
2. Set duration (1h, 4h, 8h, custom)
3. Only critical alerts will show

## Keyboard Shortcuts

View and customize shortcuts.

### Global Shortcuts

| Shortcut   | Action         |
| ---------- | -------------- |
| `Ctrl + K` | Global search  |
| `Ctrl + /` | Quick replies  |
| `Ctrl + N` | New message    |
| `Esc`      | Close modals   |
| `?`        | Show shortcuts |

### Inbox Shortcuts

| Shortcut        | Action              |
| --------------- | ------------------- |
| `Enter`         | Send message        |
| `Shift + Enter` | New line            |
| `Ctrl + E`      | Toggle emoji picker |
| `Ctrl + A`      | Attach file         |
| `Ctrl + T`      | Open templates      |

### Navigation Shortcuts

| Shortcut   | Action          |
| ---------- | --------------- |
| `G then I` | Go to Inbox     |
| `G then C` | Go to Contacts  |
| `G then T` | Go to Templates |
| `G then S` | Go to Settings  |

## Language & Region

Localization settings.

### Interface Language

Supported languages:

- English (default)
- Hindi

### Date Format

Choose display format:

- DD/MM/YYYY (31/12/2024)
- MM/DD/YYYY (12/31/2024)
- YYYY-MM-DD (2024-12-31)

### Time Format

- 12-hour (2:30 PM)
- 24-hour (14:30)

### Timezone

Set your timezone for:

- Message timestamps
- Campaign scheduling
- Analytics reports

## Chat Display

Customize conversation view.

### Message Density

| Setting         | Description           |
| --------------- | --------------------- |
| **Compact**     | More messages visible |
| **Comfortable** | Default spacing       |
| **Cozy**        | Extra spacing         |

### Chat Background

Options:

- Default gradient
- Solid color
- Custom image

### Read Indicators

Show/hide:

- Typing indicators
- Online status
- Read receipts

## Sidebar Preferences

Customize navigation sidebar.

### Collapsed Mode

- Auto-collapse on small screens
- Remember collapsed state
- Hover to expand

### Quick Access

Pin frequently used features:

1. Right-click sidebar item
2. Click **Pin to Quick Access**
3. Appears at top

### Badge Notifications

Show counts on sidebar:

- Unread messages
- Pending approvals
- Failed campaigns

## Reset Preferences

Start fresh with defaults.

### Reset Options

| Option                 | What it Resets    |
| ---------------------- | ----------------- |
| **Theme Only**         | Visual theme      |
| **Tables Only**        | Column settings   |
| **Notifications Only** | Alert preferences |
| **All Preferences**    | Everything above  |

### How to Reset

1. Go to **Settings** -> **Appearance**
2. Scroll to **Reset**
3. Choose what to reset
4. Confirm

## Per-Device Settings

Some settings are device-specific:

- Theme (syncs)
- Table columns (syncs)
- Window size (device)
- Sidebar state (device)

Settings sync across devices when logged in.

## Best Practices

1. **Use dark mode** - If working long hours
2. **Customize tables** - Show only needed columns
3. **Enable desktop notifications** - Don't miss important messages
4. **Learn shortcuts** - Increase productivity
5. **Set timezone** - Ensure accurate scheduling

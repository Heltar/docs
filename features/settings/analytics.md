# Analytics

Track performance metrics and gain insights into your WhatsApp communications.

**Navigation**: Settings -> Analytics

## WABA Analytics

WhatsApp Business Account performance overview.

### Message Metrics

| Metric                 | Description             |
| ---------------------- | ----------------------- |
| **Messages Sent**      | Total outbound messages |
| **Messages Delivered** | Successfully delivered  |
| **Messages Read**      | Opened by recipients    |
| **Messages Received**  | Inbound from customers  |
| **Failed Messages**    | Delivery failures       |

### Delivery Rates

```
Delivery Rate = (Delivered / Sent) x 100
Read Rate = (Read / Delivered) x 100
Reply Rate = (Replies / Delivered) x 100
```

### Time Period Filters

- Today
- Last 7 days
- Last 30 days
- Last 90 days
- Custom range

### Trends

View trends over time:

- Daily message volume
- Delivery rate changes
- Response time trends
- Peak activity hours

## Template Analytics

Performance metrics for message templates.

### Per-Template Metrics

| Metric        | Description              |
| ------------- | ------------------------ |
| **Sent**      | Times template was used  |
| **Delivered** | Successful deliveries    |
| **Read**      | Recipients who opened    |
| **Clicked**   | Button/link clicks       |
| **Replied**   | Recipients who responded |

### Quality Score

Templates are scored by Meta:

| Score      | Description                 |
| ---------- | --------------------------- |
| **High**   | Good engagement, low blocks |
| **Medium** | Acceptable performance      |
| **Low**    | High blocks/reports         |

Low quality templates may be:

- Paused by Meta
- Rejected for re-approval
- Rate limited

### Improving Template Performance

1. **Personalize** - Use customer name and context
2. **Be relevant** - Send to interested audiences
3. **Clear value** - Obvious benefit to recipient
4. **Good timing** - Send at appropriate times
5. **Avoid spam** - Don't over-message

## Daily Engagement

Track daily customer engagement patterns.

### Engagement Metrics

| Metric                   | Description           |
| ------------------------ | --------------------- |
| **Active Conversations** | Chats with activity   |
| **New Conversations**    | First-time contacts   |
| **Closed Conversations** | Resolved chats        |
| **Avg Response Time**    | Time to first reply   |
| **Resolution Time**      | Total time to resolve |

### Peak Hours

Identify when customers are most active:

```
Peak Activity Example:
- 9 AM - 11 AM: High
- 2 PM - 4 PM: High
- 7 PM - 9 PM: Medium
- 11 PM - 6 AM: Low
```

Use this data to:

- Schedule campaigns
- Staff appropriately
- Set auto-assign rules

## Campaign Analytics

Track bulk messaging performance.

### Campaign Metrics

| Metric         | Description            |
| -------------- | ---------------------- |
| **Total Sent** | Messages dispatched    |
| **Delivered**  | Reached recipients     |
| **Read**       | Opened messages        |
| **Failed**     | Delivery failures      |
| **Opt-Outs**   | Unsubscribes triggered |

### Failure Analysis

| Reason             | Description             |
| ------------------ | ----------------------- |
| **Invalid Number** | Not a valid WhatsApp    |
| **Blocked**        | Recipient blocked you   |
| **Rate Limited**   | Exceeded sending limits |
| **Template Error** | Variable mismatch       |
| **Network Error**  | Delivery issue          |

### Campaign Comparison

Compare campaigns:

- Delivery rates
- Engagement rates
- Best performing templates
- Audience segments

### Setting Benchmarks

Define SLAs and targets:

- First response: < 5 minutes
- Resolution time: < 24 hours
- CSAT score: > 4.5/5

## Exporting Data

Download analytics for external analysis.

### Export Formats

- CSV
- Excel (XLSX)
- PDF (reports)

### Available Exports

| Report              | Data                     |
| ------------------- | ------------------------ |
| **Message Log**     | All messages with status |
| **Campaign Report** | Campaign performance     |
| **Agent Report**    | Team metrics             |
| **Contact Export**  | Customer data            |

### Scheduling Reports

Set up automated reports:

1. Go to **Analytics** -> **Scheduled Reports**
2. Configure:
   - Report type
   - Frequency (daily/weekly/monthly)
   - Recipients (email)
3. Save

1. Go to **Analytics** -> **Dashboard**

## Best Practices

1. **Review regularly** - Check metrics weekly
2. **Set benchmarks** - Define success metrics
3. **Act on insights** - Use data to improve
4. **Compare periods** - Track improvement
5. **Share reports** - Keep team informed
6. **Investigate anomalies** - Understand spikes/drops
